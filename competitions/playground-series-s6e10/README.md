# Predicting Airline Satisfaction

- 比赛：[Kaggle Playground Series S6E10](https://www.kaggle.com/competitions/playground-series-s6e10)
- 目标：根据比赛提供的特征预测航空旅客满意度，生成正类预测概率。
- 评估指标：ROC-AUC；正式实验前核对比赛 Evaluation 页面、正类定义及提交格式。
- 当前状态：项目初始化；未下载数据、未训练、未提交。

## 后续基线计划

1. 阅读比赛规则、数据说明与 Evaluation 页面，确认目标列、ID 列、正类编码及 sample submission 格式。数据获取和参赛操作另行执行。
2. 在本地检查训练集和测试集的字段类型、缺失值、类别分布、重复记录及潜在泄漏。数据存放在被忽略的 `data/` 目录。
3. 固定随机种子，先使用分层留出验证；若数据中存在需要分组或按时间隔离的关系，调整划分方式。保留验证集，避免用公开榜分数代替本地验证。
4. 建立常数概率参考与简单的预处理加逻辑回归基线；缺失值填充和类别编码仅在训练折拟合，使用预测概率计算 ROC-AUC。
5. 在同一验证方案下比较适合表格数据的树模型（候选：CatBoost 或 LightGBM）。先记录默认基线，再决定是否调参；依赖选择与安装留待后续。
6. 记录代码提交、数据版本、随机种子、划分方法、参数及真实 ROC-AUC。需要时再增加分层交叉验证，报告均值与波动。
7. 仅在明确授权后生成并提交比赛预测；预测文件和模型文件保持在 Git 跟踪之外。
