## Supported entrypoint

Run from this directory. `describe` needs only Python's standard library:

```bash
python v12.py describe
```

For verification and exact CSV replay, use an isolated environment with the versions in `requirements-v12-replay.txt`. The original model-training environment is separately recorded in `v12_environment.json`.

```bash
python v12.py verify --artifact-root /absolute/path/to/experiment
python v12.py reproduce-csv --artifact-root /absolute/path/to/experiment --output /absolute/path/to/v12-replayed.csv
python -m unittest discover -s . -p test_v12.py
```

`v12_manifest.json` identifies 125 required artifacts and their SHA-256 hashes. Data, models, prediction caches and calibration parameters are intentionally absent from Git; the commands require the retained local experiment bundle with its relative directory structure. The verifier checks all hashes, stored validation and model-audit proofs, component IDs, calibration algebra, probabilities and CSV bytes. It uses one CPU math thread, no GPU, network, model deserialization or training. Replay refuses to overwrite a different existing file. It does not submit to Kaggle.

This is exact replay from retained artifacts, not a one-command raw-data training pipeline. The archived R68 runners document the original training and audits; running them requires their complete environment and dependencies. Do not rerun them just to reproduce the CSV.

## Frozen recipe

Clip probabilities to `[1e-6, 1-1e-6]` before taking logits:

```text
tree = .46875 LGB84 + .09375 CatBoost8 + .1875 residual57 + .25 CatBoost10
v11 = sigmoid(.5 logit(tree) + .5 logit(CE_NN74))
v12 = sigmoid(.875 logit(v11) + .125 logit(RankNet74))
```

RankNet uses the same 74 inputs, native ensemble of 32 members, seed 42, three epochs and batch size 256. Its loss is the mean pairwise softplus over positive/negative pairs within each native minibatch, with no classification cross-entropy term. Each group averages 32 probabilities and fits one training-only intercept to that group's exact training representation and positive prior. Test inference uniformly averages five calibrated groups (160 native members). This does not claim that each individual member's score origin was independently identified.

The positive class is `True=1`. Official train/test sizes are 699635/299844 with 21 raw features excluding `id` and target. Fivefold stratification uses seed 20261018; threefold uses seed 20261022.

| Validation | AUC gain over v11 | Paired 95% lower | Corrected resampled-t lower |
| --- | ---: | ---: | ---: |
| Fivefold | 0.000014425918 | 0.000004842632 | 0.000001251811 |
| Threefold | 0.000012086060 | 0.000002859134 | 0.000003393265 |

Both predeclared bounds passed on both partitions. These are conditional intervals after extensive adaptive research; the threefold partition reuses the same labels and is not an untouched holdout. The independent model audit covered eight saved model records and 256 native members across validation stages, including own-training preprocessing and CPU prediction replay.
